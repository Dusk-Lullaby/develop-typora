# 区间DP

## 1. 概述

* 区间DP：

  就是对于区间的一种动态规划，它将问题划分为若干个子区间，并通过定义状态和状态转移方程来求解每个子区间的最优解，最终得到整个区间的最优解。

  对于某个区间，它的合并方式可能有很多种，我们需要去枚举所有的方式，通常是去枚举区间的分割点，找到最优的方式（一般是找最少的消耗）。

  

* 核心思路：

  状态：`dp[i][j]`表示[i,j]的最优解

  通常都是先枚举区间长度，区间长度为1就不用合并，所以从2开始枚举，然后枚举左端点，那么右端点就为左端点区间长度-1，再枚举分割点k（即子区间的终点和起点），最后计算不同分割点k的情况下，合并区间的消耗，`dp[i][j]`选择其中最小的消耗（需要注意的是要记得根据题意给上初始值）

  长区间肯定由短区间得到，所以先算短区间。（分割点k：是从i到j - 1，因为k + 1 <= j）

  ```java
  // 先枚举区间长度
  for (int len = 2; len <= n; len++) {
      // 再枚举区间左端点，左端点加区间长度为右端点，不能大于n
      for (int i = 1; i + len - 1 <= n; i++) {
          // 区间右端点
          int j = i + len - 1;
          // 枚举区间分割点
          for (int k = i; k < j; k++) {
              dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k + 1][j] + 合并区间的消耗);
          }
      }
  }
  ```

  

## 2. 例题

[涂色](https://www.luogu.com.cn/problem/P4170)

```java
package com.lullaby.dp.region_dp.lgp1470;

import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String string = scanner.next();
        char[] chars = string.toCharArray();
        int[][] dp = new int[chars.length][chars.length];
        for (int[] arr : dp) {
            Arrays.fill(arr, 0x3f3f3f3f);
        }
        for (int i = 0; i < chars.length; i++) {
            dp[i][i] = 1;
        }
        for (int len = 2; len <= chars.length; len++) {
            for (int i = 0; i <= chars.length - len; i++) {
                int j = i + len - 1;
                if (chars[i] == chars[j]) {
                    dp[i][j] = Math.min(dp[i][j - 1], dp[i + 1][j]);
                } else {
                    for (int k = i; k < j; k++) {
                        dp[i][j] = Math.min(dp[i][k] + dp[k + 1][j], dp[i][j]);
                    }
                }
            }
        }
        System.out.println(dp[0][chars.length - 1]);
    }
}
```
