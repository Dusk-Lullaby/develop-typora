# 前缀和&差分

## 1. 前缀和

### 1.1 概述

前缀和可以简单理解为[数列的前 i 项和]，是一种重要的预处理方式。

<font color = "red" > **第1个数在数组的索引为1，不是0 ** </font>

一维：有 n 个的正整数放到数组 A 里，现在要求一个新的数组 sum。新数组的第 i 个数 sum[i] 是原数组 A 第 1 个到第 i 个数的和。

```tex
sum[1] = a[1]
sum[i] = a[1] + a[2] + ... + a[i]
sum[i - 1] = a[1] + a[2] + ... + a[i - 1]

sum[i] = sum[i - 1] + a[i]
sum[1] = a[1]

a[l] ~ a[r] = sum[r] - sum[l - 1]
a[4] ~ a[9]:
sum[9] = a[1] ~ a[9]
sum[4] = a[1] ~ a[4]
a[4] ~ a[9] = sum[4] - sum[3]
```



二维：有 n * m 个的正整数放到二维数组A中，现在要求一个新的二维数组sum，新数组sum[i] [j]是原数组A[1] [1]到A[i] [j]的和（矩形范围）

| 1，1 |      |              |           |      |      |      |
| ---- | :--: | ------------ | --------- | ---- | ---- | ---- |
|      |      |              |           |      |      |      |
|      |      | i - 1, j - 1 | i - 1， j |      |      |      |
|      |      | i , j - 1    | i，j      |      |      |      |
|      |      |              |           |      |      |      |
|      |      |              |           |      |      |      |
|      |      |              |           |      |      |      |

```tex
sum[i] [j] = sum[i - 1] [j - 1] + (sum[i] [j - 1] - sum[i - 1] [j - 1]) + (sum[i - 1] [j] - sum[i - 1] [j - 1] + a[i] [j])
```



容斥原理：

在计数时，必须注意没有重复，没有遗漏。为了使重叠部分不被重复计算，人们研究出一种计数方法，这种方法的基本思想是：先不考虑重叠的情况，把包含于某个内容中的所有对象的数目先计算出来，然后再把计数时重复计数的数目排斥出去，使得计算的结果既无遗漏又无重复，这种计数的方法称为容斥原理。



### 1. 2 例题

[洛谷：求区间和](https://www.luogu.com.cn/problem/B3612)

题目描述：给定 *n* 个正整数组成的数列 `a1,a2,⋯,a` *n* 和 *m* 个区间 [*l* *i*,*r* *i*]，分别求这 *m* 个区间的区间和。

**暴力**：

```java
import java.util.Scanner;

public class Main {
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
		int[] a = new int[n + 1];
		for (int i = 1; i <= n; i++) {
			a[i] = sc.nextInt();
		}
		int m = sc.nextInt();
		for (int i = 0; i < m; i++) {
			int sum = 0;
			int l = sc.nextInt();
			int r = sc.nextInt();
			for (int j = l; j <= r; j++) {
				sum += a[j];
			}
			System.out.println(sum);
		}
	}
}

```

> 暴力做法的时间复杂度是O（m * n），由于n和m 都是10 ^ 5，m * n 最高达到 10 ^ 10 所以会`TLE`。

**前缀和**：

```java
import java.util.Scanner;

public class Main {
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
//		int[] a = new int[n + 1];
		// sum数组来计算前缀和
		int[] sum = new int[n + 1];
		for (int i = 1; i <= n; i++) {
//			a[i] = sc.nextInt();
			sum[i] = sum[i - 1] + sc.nextInt();
		}
		
		int m = sc.nextInt();
		for (int i = 0; i < m; i++) {
			int r = sc.nextInt();
			int l = sc.nextInt();
			System.out.println(sum[l] - sum[r - 1]);
		}
	}
}

```

> 时间复杂度为O(m + n)



[洛谷：最大正方形](https://www.luogu.com.cn/problem/P1387)

题目描述：在一个 *n*×*m* 的只包含 0 和 1 的矩阵里找出一个不包含 0 的最大正方形，输出边长。

```java
import java.util.Scanner;

public class Main {
	static int n;
	static int m;
	static int[][] arr;
	static int[][] sum;
	static int max;
	
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		n = sc.nextInt();
		m = sc.nextInt();
		arr = new int[n + 1][m + 1];
		sum = new int[n + 1][m + 1];
		
		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				arr[i][j] = sc.nextInt();
				sum[i][j] = sum[i - 1][j] + sum[i][j - 1] - sum[i - 1][j - 1] + arr[i][j];
			}
		}
		
		for (int i = 1; i <= n; i++) {
			for (int j = 1; j <= m; j++) {
				for (int k = 1; k <= Math.min(i, j); k++) {
					if (sum[i][j] - sum[i][j - k] - sum[i - k][j] + sum[i - k][j - k] == Math.pow(k, 2)) {
						max = max > k ? max : k;
					}
				}
			}
		}
		
		System.out.println(max);
	}
}

```
