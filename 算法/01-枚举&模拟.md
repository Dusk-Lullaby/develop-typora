# 枚举&模拟

## 1. 枚举

枚举：是基于已有的知识来猜测答案的一种问题求解策略。

枚举的思想是不断地猜测，从可能的答案集合之中一一尝试，然后再判断题目的条件是否成立。枚举每一种可能性。



## 2. 模拟

模拟：直接模拟题目中要求的操作来求解。

模拟题目通常具有码量大，操作多的特点。由于它码量大，经常会出现难以差错的情况。



## 3. 例题

[例1：铺地毯](https://www.luogu.com.cn/problem/P1003)

在平面直角坐标系中，按编号 1 到 n 的顺序依次铺设 n 张矩形地毯。后铺的地毯会覆盖在先铺的地毯之上（包含边界和顶点）。

已知每张地毯的左下角坐标及长宽，求最终覆盖在指定目标点 (x, y) 上最顶层的地毯编号。

输入数据结构：

- 第 1 行：地毯总数 n。

- 第 2 到 n+1 行：每行 4 个整数 a, b, g, k，依次表示第 i 张地毯的左下角坐标 (a, b)，以及沿 x 轴长度 g 和沿 y 轴长度 $k$。

- 最后 1 行：需要查询的目标点坐标 x, y。

  

<font color = ”blue> 一周目：</font> 

```java
import java.util.Scanner;

public class Main {

	public static void main(String[] args) {
		
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
		int max = 1001;
		int[][] table = new int[max][max];
		
		for (int i = 1; i <= n; i++) {
			int a = sc.nextInt();
			int b = sc.nextInt();
			int g = sc.nextInt();
			int k = sc.nextInt();
			for (int j = b; j <= b + k; j++) {
				for (int l = a; l <= a + g; l++) {
					table[j][l] = i;
				}
			}
		}
		
		int x = sc.nextInt();
		int y = sc.nextInt();
		if (table[y][x] == 0) table[y][x] = -1;
		System.out.println(table[y][x]);
	}
}

```

> 数组开不了10 ^ 5
>
> 可以通过4个数组来存储地毯的信息

```java
import java.util.Scanner;

public class Main {

	public static void main(String[] args) {
		
		Scanner sc = new Scanner(System.in);
		int max = 10005;
		int[] a = new int[max];
		int[] b = new int[max];
		int[] g = new int[max];
		int[] k = new int[max];
		
		int n = sc.nextInt();
		for (int i = 1; i <= n; i++) {
			a[i] = sc.nextInt();
			b[i] = sc.nextInt();
			g[i] = sc.nextInt();
			k[i] = sc.nextInt();
		}
		
		int x = sc.nextInt();
		int y = sc.nextInt();
		boolean flag = false;
		for (int i = n; i > 0; i--) {
			if (a[i] <= x && a[i] + g[i] >= x && b[i] <= y && b[i] + k[i] >= y) {
				System.out.println(i);
				flag = true;
				break;
			}
		}
		
		if (!flag) {
			System.out.println(-1);
		}
		
	}
}

```
