# 反悔堆

## 1. 概念

反悔堆（反悔贪心）是贪心算法的一种扩展策略。标准贪心算法存在“目光短浅”的缺陷：一旦做出选择，就无法更改，容易陷入局部最优。

反悔贪心通过引入优先队列（堆）来解决这一问题。它的核心思想是：**先无脑接受当前的贪心选择，如果发现后续状态不合法（如超载、超时），再从已做出的选择中，撤销（反悔）代价最大/收益最小的那一个。** 这种“边选边反悔”的机制保证了最终结果的全局最优。



## 2. 步骤

反悔贪心通常用于解决**带有容量或时间限制的最优化问题**。基本流程分为四步：

1. **基础排序**：将所有候选元素按照某种基准排序（通常是按限制条件的紧迫程度，例如截止时间从小到大，或单价从低到高）。
2. **盲目入堆**：遍历排序后的元素，优先假设选择当前元素，更新当前的状态值（如总耗时、总重量），并将该元素的关键代价（如耗时、重量）压入优先队列（大根堆或小根堆）。
3. **合法性检验**：判断加入当前元素后，整体状态是否超出了限制。
4. **触发反悔**：如果状态不合法，比较当前堆顶元素（已选项中最差的决策）和当前面临的限制。弹出堆顶元素（即撤销最差的选择），扣除其代价，使状态重新恢复合法。



## 3. 模板

```java
import java.util.Arrays;
import java.util.PriorityQueue;

public class RegretGreedy {
    // tasks[i] = {duration, deadline}
    public int maxTasks(int[][] tasks) {
        // 1. 基础排序：按截止时间从小到大排序
        Arrays.sort(tasks, (a, b) -> a[1] - b[1]);
        
        // 2. 大根堆：维护已选任务的持续时间（耗时长的在堆顶）
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        int totalTime = 0;
        
        // 3. 遍历决策
        for (int[] task : tasks) {
            int duration = task[0];
            int deadline = task[1];
            
            // 无脑假设选择当前任务
            totalTime += duration;
            maxHeap.offer(duration);
            
            // 4. 合法性检验与反悔
            // 如果总耗时超过了当前任务的截止时间，说明需要放弃一个最耗时的任务
            if (totalTime > deadline) {
                // 弹出堆顶（可能是刚刚加入的当前任务，也可能是历史选择的任务）
                totalTime -= maxHeap.poll(); 
            }
        }
        
        // 最终堆内的元素个数就是最大合法选择数
        return maxHeap.size();
    }
}
```
