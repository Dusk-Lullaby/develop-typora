# 快速幂

## 1. 概述

快速幂（Fast Exponentiation）是一种用于高效计算大整数幂 a^n 的算法。

在常规逻辑下，计算 a^n 需要将 a 连乘 n 次，时间复杂度为 O(n)。当 n 非常大（例如几千万、十几亿）时，程序会因为循环次数过多而超时。快速幂通过**将指数转化为二进制进行分治**，将时间复杂度降至 O(\log n)。这意味着即使 n 是十亿量级，也只需要进行约 30 次循环。

<font color = "red" >**核心计算原理**：把指数拆成2的幂次值和。</font>

> 以3  ^ 13 为例：
>
> 普通算法：3 * 3 * 3 ··· * 3 （连续乘13次）
>
> 快速幂算法：
>
> 1. 先将13变为二进制：1101
> 2. 将二进制拆解为十进制的加法：13 = 8 + 4 + 1
> 3. 利用指数乘法法则：3  ^ 13 = 3 ^ (8 + 4 + 1)

模数（Modulus，简称 Mod）指**取模运算（即求余运算）中的除数**。在数学表达式 `a mod m` 或编程语言的 `a % m` 中，m 就是模数。

> **加法**：(a + b) mod m = ((a mod m) + (b mod m)) mod m
>
> **乘法**：(a * b) mod m = ((a mod m) * (b mod m)) mod m
>
> 

## 2. 模板

```java
/**
 * 计算 (base^exp) % mod
 * 时间复杂度: O(log exp)
 * * @param base 底数
 * @param exp  指数
 * @param mod  模数
 * @return 计算结果
 */
public static long qpow(long base, long exp, long mod) {
    // result累乘器
    long res = 1;
    base = base % mod; // 预处理：防止初始 base 大于 mod 导致后续相乘溢出
    
    while (exp > 0) {
        // 如果指数当前最低位为 1，将当前的 base 乘入结果
        if ((exp & 1) == 1) {
            res = (res * base) % mod;
        }
        // base 进行平方运算，并取模
        base = (base * base) % mod;
        // 指数右移一位，处理下一位二进制
        exp >>= 1;
    }
    
    return res;
}
```

## 3. 例题

[例1：洛谷P1226](https://www.luogu.com.cn/problem/P1226)

题目描述：给你三个整数 *a*,*b*,*p*，求 *a ^ b* mod *p*。

<font color = "blue"> 一周目：</font>

```java
import java.util.Scanner;

public class Main {
	
	public static void main(String[] args) {
		
		Scanner sc = new Scanner(System.in);
		long a = sc.nextLong();
		long b = sc.nextLong();
		long p = sc.nextLong();
		long res = qpow(a, b, p);
		System.out.println(a + "^" + b + " mod " + p + "=" + res);
	}
	
	public static long qpow(long base, long exp, long MOD) {
		long res = 1;
		base = base % MOD;
		while (exp > 0) {
			if ((exp & 1) == 1) {
				res = res * base % MOD;
			}
			base = base * base % MOD;
			exp = exp >> 1;
		}
		return res;
	}
}
```

[例2：洛谷P15966](https://www.luogu.com.cn/problem/P15966)

题目条件：给定目标等级 x 和基础元素的最大可用等级 y。 你可以使用任意数量的基础元素，每个元素的初始等级可指定为 0 到 y 之间的任意整数。

合成规则：每次操作可将一排相邻的元素合成为一个新元素，新元素的等级等于被合成元素中不同等级的种类数。

求解目标：求合成出等级为 x 的元素，最少需要消耗多少个初始基础元素。将最终结果对 998244353 取模后输出。



<font color = "blue"> 一周目：</font>

```java

/*
 * n m
 * 3 2
 * 0 1 2
 * 一开始获得最高等级 n + 1
 * 
 * 10 5
 * 6base --- lv6(base) --- 6 * 2^(lv - 5 - 1)
 * 6base + lv6(6base) --- lv7(12base) --- 6 * 2^(7 - 5 - 1) = 12
 * 6base + lv6(6base) + lv7(12base) --- lv8(24base) --- 6 * 2^(8 - 5 - 1) = 24
 * 6base + lv6(6base) + lv7(12base) + lv8(24base) --- lv9(48base)
 * 6base + lv6(6base) + lv7(12base) + lv8(24base) + lv9(48base) --- lv10(96base)
 * 10 5
 * 6 * 2^(10 - 1- 5) = 6 * 2^4 = 6 * 16 = 96
 * 
 * 20 13
 * 14 * 2^(20 - 1- 13) = 14 * 2^6 = 14 * 64
 * 
 * (m + 1) * 2^(n - 1 - m)
 */

import java.util.Scanner;

public class Main {
	
	public static void main(String[] args) {
		
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
		for (int i = 0; i < n; i++) {
			long a = sc.nextLong();
			long b = sc.nextLong();
			long c = (b + 1) * ((long)Math.pow(2, a - 1 - b));
			System.out.println(c % 998244353);
		}
	}
	
}

```

> 1. **`Math.pow` 精度限制与 `long` 溢出**
>
> - **错误原因**：`Math.pow` 底层使用浮点数计算，返回值为 `double`，无法保证大整数的绝对精度。当指数 a - 1 - b >= 63 时，2^(a-1-b) 的值会直接超出 `long` 类型的最大上限（2^63-1），强转 `(long)` 后会得到错误的数据或负数。
>
> 2. **取模时机错误（未防止中间过程溢出）**
>
> - **错误原因**：算法题中要求对 998244353 取模，意味着数据规模极大，必须**在乘法和指数放大的每一个步骤中边算边取模**。代码中 `c % 998244353` 仅在最后一步执行，毫无意义，因为在这之前 `c` 早就已经溢出了。
>
> 3. **修正方案**：引入快速幂算法来计算指数部分，并且最后的乘法计算时再次取模。
>
>    (m + 1) * 2^(n - 1 - m)  --->  (m + 1) (mod MOD) * 2 ^ (n - 1 - m)(mod MOD) (mod MOD)



<font color = "blue"> Java 实现：</font>

```java
import java.util.Scanner;

public class Main {
	
	static final long MOD = 998244353;
	public static void main(String[] args) {
		
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
		for (int i = 0; i < n; i++) {
			long a = sc.nextLong();
			long b = sc.nextLong();
			// 当a < b 时直接输出1
			if(a < b) {
				System.out.println(1);
				continue;
			}
			long exp = a - 1 - b;
			long res = (b + 1) % MOD * qpow(2, exp) % MOD;
			System.out.println(res % MOD);
		}
	}
	
	public static long qpow(long base, long exp) {
		long res = 1;
		base = base % MOD;
		while (exp > 0) {
			if ((exp & 1) == 1) {
				res = (res * base) % MOD;
			}
			base = base * base % MOD;
			exp = exp >> 1;
		}
		
		return res;
	}
	
}
```

#include <stdio.h>

const long long MOD = 998244353;

long long qpow(long long base, long long exp) {
    long long res = 1;
    base = base % MOD;
    while (exp > 0) {
        if ((exp & 1) == 1) {
            res = (res * base) % MOD;
        }
        base = (base * base) % MOD;
        exp = exp >> 1;
    }
    return res;
}

int main() {
    int n;
    // 读取测试用例数量
    if (scanf("%d", &n) == 1) {
        for (int i = 0; i < n; i++) {
            long long a, b;
            scanf("%lld %lld", &a, &b);
            
            // 当 a < b 时直接输出 1
            if (a < b) {
                printf("1\n");
                continue;
            }
            
            long long exp = a - 1 - b;
            long long res = (b + 1) % MOD * qpow(2, exp) % MOD;
            printf("%lld\n", res % MOD);
        }
    }
    
    return 0;
}
