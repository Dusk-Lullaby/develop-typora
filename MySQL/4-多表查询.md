# 多表查询

## 1. 表与表之间的联系

### 1.1 主外键关联

```sql
CREATE TABLE stu(
  number BIGINT(20) AUTO_INCREMENT NOT NULL COMMENT '学号',
  `name` VARCHAR(30) NOT NULL COMMENT '姓名',
  sex VARCHAR(2) NOT NULL DEFAULT '男' COMMENT '性别',
  age TINYINT(3) UNSIGNED DEFAULT 0 COMMENT '年龄',
  class_id INT(11) NOT NULL COMMENT '所属班级',
  -- 指定number为主键
  PRIMARY KEY(number), 
  -- 指定class_id为外键，关联的是class表中的id
  FOREIGN (class_id) REFERENCES class(id)
) ENGINE=INNODB CHARSET=UTF8 COMMENT='学生表';
```

### 1.2 约束

**主键约束**

```sql
-- 添加主键约束：保证数据的唯一性
ALTER TABLE 表名 ADD PRIMARY KEY(字段名1， 字段名2，···， 字段名n);
-- 删除主键约束
ALTER TABLE 表名 DROP PRIMARY KEY;
```

**外键约束**

```sql
-- 添加外键约束
ALTER TABLE 表名1 ADD CONSTRAINT 外键名称 FOREIGN KEY(表名1的字段) REFERENCES 表名2(表名2的字段名);
-- 删除外键约束
ALTER TABLE 表名 DROP FOREIGN KEY 外键名称;
```

**唯一约束**

```sql
-- 添加外键约束
ALTER TABLE 表名1 ADD CONSTRAINT 约束名称 UNIQUE(字段名1，字段名2，···，字段名n);
-- 删除字段的唯一约束
ALTER TABLE 表名 DROP KEY 约束名称;
```

**非空约束**

```sql
-- 为字段添加非空约束
ALTER TABLE 表名 MODIFY 字段名 列类型 NOT NULL;
-- 删除字段非空约束
ALTER TABLE 表名 MODIFY 字段名 列类型 NULL；
```

**默认值约束**

```sql
-- 为字段添加默认值
ALTER TABLE 表名 ALTER 字段名 SET DEFAULT 默认值;
-- 删除字段的默认值
ALTER TABLE 表名 ALTER 字段名 DROP DEFAULT；
```

**自增约束**

```sql
-- 为字段添加自增约束
ALTER TABLE 表名 MODIFY 字段名 列类型 AUTO_INCREMENT;
-- 为字段删除自增约束
ALTER TABLE 表名 MODIFY 字段名 列类型;
```



## 2. 索引

在关系数据库中，索引是一种单独的、物理的对数据库表中一列或多列的值进行排序的一种存储结构，它是表中一列或多列值的集合和相应的指向表中物理标识这些值的数据页的逻辑指针清单。

**索引的类型**

1. 唯一索引（UNIQUE）：不可以出现相同的值， 可以有NULL
2. 普通索引（INDEX）：允许出现相同的索引内容
3. 主键索引（PRIMARY KEY）：不允许出现相同的值，不允许NULL
4. 全文索引（FULLTEXT INDEX）：可以针对值中的某个单词，但效率确实不敢恭维
5. 组合索引：实质上是将多个字段建到一个索引里，列值的组合必须唯一

**索引的创建、查看、删除**

```sql
-- 创建索引
ALTER TABLE 表名 ADD INDEX 索引名称（字段名1，字段名2，···，字段名n）;
-- 创建全文索引
ALTER TABLE 表名 ADD FULLTEXT 索引名称（字段名1， 字段名2， ···， 字段名n）;
-- 查看索引
SHOW INDEX FROM 表名;
-- 删除索引
ALTER TABLE 表名 DROP INDEX 索引名称;
```

**使用索引的注意事项**

* 虽然索引大大提高了查询速度，但也会降低更新表的速度，比如对表进行INSERT，UPDATE和DELETE操作时，此时，数据库不仅要保存数据，还会保存一下索引文件
* 建立索引会占据磁盘空间的索引文件。如果索引创建过多（尤其是在字段多、数据量大的表上创建索引），就会导致索引文件过大，这样反而会降低数据库性能。因此，索引要建立在经常进行查询操作的字段上。
* 不要在列上进行运算（包括函数运算），这会忽略索引的使用
* 不建议使用LIKE操作，如果非用不可，注意正确的使用方式。LIKE'%查询内容%'不会使用索引，而LIKE'查询内容%'会使用索引。
* 避免使用IS NULL、 NOT IN 、<>、！=、OR操作，这些操作都会忽略索引进行全表扫描



## 3. 多表查询

### 3.1 笛卡尔积

对于两个集合 A 和 B，它们的笛卡尔积表示为 A * B，指的是由这两个集合中所有可能的有序对组成的集合。其中，每个有序对的第一个元素必须来自 A，第二个元素必须来自 B。

### 3.2 内连接

内连接相当于在笛卡尔积的基础上加了连接条件。当没有连接条件时，内连接上升为笛卡尔积

```sql
SELECT 字段名1， 字段名2， ···， 字段名n FROM 表1 [INNER] JOIN 表2 [ON 连接条件];

SELECT 字段名1， 字段名2， ···， 字段名n FROM 表1， 表2 [WHERE 关联条件 AND 查询条件];
```

<font color = "blue">示例：</font>

```sql
SELECT COUNT(*) FROM stu;
SELECT COUNT(*) FROM score;

SELECT COUNT(*) FROM stu, score;

SELECT COUNT(*) FROM stu INNER JOIN score ON stu.id=score.stu_id;

SELECT COUNT(*) FROM stu, score WHERE stu.id=score.stu_id;
```

### 3.3 外连接

外连接涉及到两张表：主表和从表，要查询的信息主要来自于哪张表，哪张表就是主表。

<font color = "red">**外连接查询的结果为主表中的所有记录。如果从表中有和它匹配的，则显示匹配的值，这部分相当于内连接查询出来的结果；如果从表中没有和它匹配的，则显示为null**</font>

<font color = "red">**外连接查询的结果 = 内连接的结果 + 主表中有的而内连接结果中没有的记录**</font>

外连接分为左外连接和右外连接两种。在左外连接使用LEFT JOIN关键字，LEFT JOIN左边的是主表；右外连接使用RIGHT JOIN关键字，RIGHT JOIN右边的是主表。

#### 3.3.1 左外连接

```sql
SELECT 字段名1， 字段名2， ···， 字段名n FROM 主表 LEFT JOIN 从表[ON 连接条件];
```

<font color = "blue">示例：</font>

```sql
SELECT * FROM stu a LEFT JOIN score b ON a.id=b.stu_id;
```

#### 3.3.2 右外连接

```sql
SELECT 字段名1， 字段名2， ···， 字段名n FROM 从表 RIGHT JOIN 主表[ON 连接条件];
```

<font color = "blue">示例：</font>

```sql
SELECT 字段名1， 字段名2， ···， 字段名n FROM 主表 LEFT JOIN 从表[ON 连接条件];
```



## 4. 子查询

子查询就是嵌套子其他查询中的查询，因此，子查询出现的位置只要3种情况：在SELECT····FROM之间、在FROM···WHERE之间、在WHERE之后。

**SELECT···WHERE之间**

执行时机是在查询结果出来之后

查询stu表种所有的学生信息，并按性别按男、女、其他展示

```sql
SELECT
  id,
  `name`,
  (SELECT text FROM dict WHERE type='sex' AND value=sex) sex,
  birthday,
  class
FROM
  stu;
```

**FROM···WHERE之间**

执行时机是一开始就执行

查询年龄与Java成绩都与汤辰宇的年龄的成绩与Java成绩相同的学生信息

```sql
-- 查询年龄与Java成绩都与汤辰宇的年龄的成绩与Java成绩相同的学生信息
SELECT * FROM stu c 
INNER JOIN 
	score d ON c.id=d.stu_id
INNER JOIN 
	(SELECT 
 		a.`name`, 
 		TIMESTAMPDIFF(YEAR,a.birthday,NOW()) age, 
 		b.score 
 	FROM stu a INNER JOIN score b ON a.id=b.stu_id 
 	WHERE a.name='汤辰宇' AND b.course='Java') e
ON TIMESTAMPDIFF(YEAR,c.birthday,NOW())=e.age AND d.score=e.score
WHERE d.course='Java';
```

**WHERE之后**

执行时机是一开始就执行

查询Java成绩最高的学生信息

```sql
-- 查询Java成绩最高的学生信息
SELECT a.*, b.* FROM stu a INNER JOIN score b ON a.id=b.stu_id WHERE 
(SELECT MAX(score) FROM score WHERE course='Java')=b.score AND b.course='Java';
```
