# Develop Notes

个人编程学习笔记仓库，记录从编程语言基础、数据结构与算法，到数据库、Web 前端和 Java Web 开发的学习内容。

笔记主要使用 Markdown 编写，并配有代码示例、知识结构图和部分 PDF 版本，适合日常复习与快速查阅。

## 使用方式

克隆仓库：

```bash
git clone git@github.com:Dusk-Lullaby/develop-typora.git
cd develop-typora
```

使用 Typora、VS Code 或任意支持 Markdown 的编辑器打开仓库即可阅读。部分笔记包含本地图片资源，建议克隆完整仓库后查看。

> 本仓库是持续整理中的个人学习记录，内容可能随学习进度不断补充和修正。

## 说明

- 笔记中的示例以学习和理解知识点为主。
- 图片资源分别保存在各主题的 `image`、`img` 或 `photo` 目录中。
- PDF 为部分 Markdown 笔记的导出版本；仓库已配置忽略新增的 PDF 文件。
