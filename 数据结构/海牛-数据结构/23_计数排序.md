# 计数排序

## 1. 概述

冒泡，选择，插入，归并，快速，希尔，堆排序，都是基于比较的排序，这些基于比较的排序，有以下几个特点：平均复杂度最低的是O（`nlogn`）

而计数排序，不是基于比较的排序。其中不基于比较的排序还有桶排序，基数排序等

它们是典型的用空间换时间，在某些时候，平均复杂度可以比O（`nlogn`）更低，也就是说，在某些时候，这种利用空间换时间的排序算法，性能比前面基于比较的算法更快。



## 2. 计数排序

统计每个整数在序列中出现的次数，进而推导出每个整数在有序序列中的索引。

以数组[1,4,1,2,5,2,4,1,8]为例

1. 建立一个初始化为0，长度为9（原始数组中的最大值加1）的数组count[]
2. 遍历数组，访问第一个元素1，然后将数组标为1的元素加1，表示当前1出现了1次，即count[1] = 1
3. 依次遍历 ---> [1,1,2,2,4,4,5,8]



## 3. 优化

1. 无法对负整数进行排序
2. 及其浪费空间
3. 是一个不稳定排序



不再以输入数列的最大值+1作为统计数组的长度，而是以数列[最大值 - 最小值 + 1] 作为统计数组的长度即可。数列的最小值作为一个偏移量，用于计算整数在统计数组的下标。

比如：95 94 91 98 99 90 99 93 91 92

统计出数组的长度为99 - 90 + 1 = 10，偏移量等于数组的最小值90，对于第一个整数95，对应的统计数组下标是95 - 90 = 5
