# 03_栈

表的插入和删除只能在一端进行，先进后出



## 3.1 顺序栈

1. 满栈： 栈顶指针指向最后一个**入栈的数据**
2. 空栈： 栈顶指针指向下一个**可用的空位置**
3. 递增栈： 栈向**高地址**方向增长
4. 递减栈： 栈向**低地址**方向增长



### 3.1.1 申明

顺序栈中存在一个数组用来存储元素，同时需要一个指针来指向栈顶。数组所存储的空间是有限的， 因此需要设定一个最大值。

### 3.1.3 压栈

在压栈前先要判断是否满栈，满栈直接返回；若仍可以进行压栈操作，以满递增栈为例，需要先移动top指针，再入栈。

<font color = "blue"> C 实现： </font>

```c
/*压栈*/
int pushArrayStack(ArrayStack_t* stack, Element_t e) {
	//判断overFlow
	if (stack->top >= MAXSIZE - 1) {
		printf("overFlow\n");
		return -1;
	}

	//push
	stack->data[++stack->top] = e;

	return 0;
}
```

```java
        //overFlow
        if (this.top >= MAXSIZE - 1) {
            System.out.println("overFlow");
            return false;
```

### 3.1.4 出栈

在出栈时需要考虑栈是否为空， 如果为空则失败；进行出栈操作时，先出栈再移动指针

<font color = "blue"> C 实现：</font>

```c
/*出栈*/
int popArrayStack(ArrayStack_t* stack, Element_t* e) {
	//underFlow
	if (stack->top < 0) {
		printf("underFlow\n");
		return -1;
	}

	//pop
	Element_t tmp = stack->data[stack->top--];
	if (e) {
		*e = tmp;
	}

	return 0;
}

```

```java
            System.out.println("underFlow");
            return false;
        }

    }

```

## 3.2 链栈

### 3.2.3 压栈

进行压栈操作时， 因为是尾插法， 所以top指针会指向新节点。如果老节点的next指向新节点，那么在进行出栈操作时，无法找到前驱节点。因此需要让新节点的next指向老节点，在移动top指针，这样进行出栈操作时，就可以通过next找到上一个节点。

<font color = "blue"> C 实现：</font>

```c
/*push*/
int pushLinkStack(LinkStack_t* stack, value_t val) {
	//创建节点
	node_t* node = malloc(sizeof(node_t));
	if (node == NULL) {
		printf("malloc failed\n");
		return -1;
	}

	//push
	node->val = val;
	node->next = stack->top;
	stack->top = node;
	stack->count++;

	return 0;
}
```



<font color = "blue"> Java 实现：</font>

```java
    /*
        功能： 压栈

            return false;

        Node node = new Node(element);

        node.next = this.top;
```

### 3.2.4 出栈

出栈前需要判断栈是否为空，在进行出栈操作时，定义临时指针指向栈顶，让top指针指向上一个节点，然后释放临时指针即可。

<font color = "blue"> C 实现： </font>

```c
/*pop*/
int popLinkStack(LinkStack_t* stack, value_t* val) {
	//underFlow
	if (stack->count <= 0) {
		printf("underFlow\n");
		return -1;
	}

	//pop
	node_t* tmp = stack->top;
	stack->top = stack->top->next;
	if (val) {
		*val = tmp->val;
	}
	free(tmp);
	stack->count--;

	return 0;
}
```

```java
package com.Sonnet.LinkStack;

public class LinkStack {

    //节点结构
    private class Node {
        Element element;
        Node next;

        public Node() {};
        public Node(Element element) {
            this.element = element;
        }
    }

    private int count;
    private Node top;

    public LinkStack() {
        this.count = 0;
        this.top = null;
    }

    /*
        功能： 压栈
        参数： 需要压入的元素
        返回值： 成功true 失败false
     */
    public boolean pushLinkStack(Element element) {
        if (element == null) {
            return false;
        }

        //创建节点
        Node node = new Node(element);

        //push
        node.next = this.top;
        this.top = node;
        this.count++;

        return true;
    }

    /*
        功能： 弹栈
        参数： 无
        返回值： 成功true 失败false
     */
    public boolean popLinkStack() {
        //判断链栈为空
        if (this.count <= 0) {
            System.out.println("underFlow");
            return false;
        }

        //pop
        Node tmp = this.top;
        this.top = this.top.next;
        this.count--;
        //释放节点
        tmp.element = null;
        tmp.next = null;

        return true;
    }

    /*
    功能： 弹栈
    参数： 无
    返回值： 出栈的元素
 */
    public Element popLinkStackElement() {
        //判断链栈为空
        if (this.count <= 0) {
            System.out.println("underFlow");
            return null;
        }

        //pop
        Node tmp = this.top;
        this.top = this.top.next;
        this.count--;
        //释放
        Element e = tmp.element;
        tmp.element = null;
        tmp.next = null;

        return e;
    }

    /*
        功能： 释放链栈
        参数： 无
        返回值： 无
     */
    public void releaseLinkStack() {
        //临时指针tmp
        Node tmp;
        while (this.top != null) {
            tmp = this.top;
            this.top = this.top.next;
            //释放节点
            tmp.element = null;
            tmp.next = null;
        }
    }

    /*
        功能： 获取栈顶元素
        参数： 无
        返回值： 无
     */
    public Element getElement() {
        return this.top.element;
    }
}
```
