# 04_队列

**先进先出**，操作行为上，只能在两端进行操作。一端是写，一端是读。写端是：队尾，读端是队头。

## 4.1 顺序队列

顺序队列中用数组来存储数据，由于需要对两端进行操作，因此还需要头尾指针来辅助。入队时尾指针后移，出队时头指针也需要后移，随着头尾指针的后移，数组中可用的空间也就越来越少，因此需要让头尾指针循环起来，指针到末尾时，循环到开端，为了实现这一操作可以采用**取模**的方法。

当队列为满和队列为空的条件一样，都是首尾指针相等，为了解决这个问题，可以引入计数器，但更推荐**牺牲一个数组空间**，当队列为满时`（rear + 1） % MAXSIZE == front`当队列为空时就是`rear == front`。

栈的压栈和弹栈操作顺序相反，比如压栈为先后移指针再压入，弹栈就为先弹出再移动指针。而队列恰好与栈相反，**操作顺序都一致，如果入队是先加入元素再后移指针，那么出队也为先移出元素再移动指针。**

### 4.1.3 入队

顺序队列进行入队前需要判断队列是否为满，再更新队列。由于牺牲了一个数组空间，来辅助判断，因此判断条件为`（rear + 1） % MAXSIZE == front`。

<font color = "blue"> C 实现： </font>

```c
/*入队*/
int enArrayQueue(ArrayQueue_t* queue, Element_t element) {
	//判断队列是否为满
	if (((queue->rear + 1) % MAXSIZE == queue->front)) {
		printf("full\n");
		return -1;
	}
	//入队
	//先入队再后移
	queue->data[queue->rear] = element;
	queue->rear = (queue->rear + 1) % MAXSIZE;

	return 0;
}
```

### 4.1.4 出队

与入队相似，需要先判断队列是否为空，其判断条件为`front == rear`, 然后再更新队列

<font color = "blue"> C 实现：</font>

```c
/*出队*/
int deArrayQueue(ArrayQueue_t* queue, Element_t* element) {
	//判断空
	if (queue->front == queue->rear) {
		printf("empty\n");
		return -1;
	}
	// 出队
	// 先出队再后移
	if (element) {
		*element = queue->data[queue->front];
	}
	queue->front = (queue->front + 1) % MAXSIZE;

	return 0;
}
```

## 4.2 链式队列



### 4.2.1 申明

由于进行入队操作时，使用的是尾插法，因此不需要头节点，只需要头指针，由于用链式结构，因此还要定义节点结构。

<font color = "blue"> C 实现：</font>

```c
typedef int value_t;

typedef struct _node {
	value_t val;
	struct _node* next;
}node_t;

typedef struct {
	int count;
	node_t* front;
	node_t* rear;
}LinkQueue_t;
```

### 4.2.3 入队

链式队列入队时需要分第一次入队，和普通入队，第一次入队，需要让首位指针都指向新节点。

<font color = "blue"> C 实现：</font>

```c
/*入队*/
int enLinkQueue(LinkQueue_t* queue, value_t val) {
	//开辟空间
	node_t* node = malloc(sizeof(node_t));
	if (node == NULL) {
		printf("malloc failed\n");
		return -1;
	}
	//赋值
	node->next = NULL;
	node->val = val;
	//第一次入队
	if (queue->front == NULL) {
		queue->front = node;
		queue->rear = node;
	}
	//入队
	else {
		queue->rear->next = node;
		queue->rear = node;
	}
	queue->count++;

	return 0;
}

/*出队*/
int deLinkQueue(LinkQueue_t* queue, value_t* val) {
	if (queue == NULL) return -1;
	//判断队列是否为空
	if (queue->front == NULL) {
		printf("empty\n");
		return -1;
	}
	//出队
	node_t* tmp = queue->front;
	if (val) {
		*val = tmp->val;
	}
	queue->front = tmp->next;
	free(tmp);
	queue->count--;
	// 最后一个元素出队时，需要小心rear变为野指针
	if (queue->front == NULL) {
		queue->rear = NULL;
	}

	return 0;
}

```



<font color = "blue"> Java 实现：</font>

```java
    /*
        功能： 入队
        参数： 需要入队的元素

    public boolean enLinkQueue(Element element) {
        if (element == null) {
            return false;
        }
        //创建新节点
        Node node = new Node(element, null);
        //第一次入队

            this.front = node;
            this.rear = node;
```

### 4.2.4 出队

在出队时需要注意判断队列是否为空，同时，当最后一个元素出队时，尾指针可能变成野指针。

<font color = "blue"> C 实现：</font>

```c

	if (val) {
		*val = tmp->val;
	}
	queue->front = tmp->next;
	free(tmp);
	queue->count--;
	// 最后一个元素出队时，需要小心rear变为野指针

	}
```

`LinkQueue.c`:

```c
#include <stdio.h>
#include <stdlib.h>
#include "LinkQueue.h"

/*create*/
LinkQueue_t* createLinkQueue() {
	//开辟空间
	LinkQueue_t* queue = malloc(sizeof(LinkQueue_t));
	if (queue == NULL) {
		printf("malloc failed\n");
		return NULL;
	}
	//初始化
	queue->count = 0;
	queue->front = NULL;
	queue->rear = NULL;

	return queue;
}

/*release*/
void releaseLinkQueue(LinkQueue_t* queue) {
	//判断为空
	if (queue) {
		//临时指针
		node_t* tmp;
		while (queue->front) {
			tmp = queue->front;
			queue->front = tmp->next;
			free(tmp);
			queue->count--;
		}
		printf("queue have %d node\n", queue->count);
		free(queue);
	}
}

/*入队*/
int enLinkQueue(LinkQueue_t* queue, value_t val) {
	//创建新节点
	node_t* node = malloc(sizeof(node_t));
	if (node == NULL) {
		printf("malloc failed\n");
		return -1;
	}
	node->val = val;
	node->next = NULL;
	//入队
	//如果尾指针存在
	if (queue->rear) {
		queue->rear->next = node;
		queue->rear = node;
	}
	//首次入队
	else {
		queue->front = node;
		queue->rear = node;
	}
	queue->count++;

	return 0;
}

/*出队*/
int deLinkQueue(LinkQueue_t* queue, value_t* val) {
	//判断是否为空
	if (queue == NULL) return -1;
	if (queue && queue->front == NULL) {
		printf("empty\n");
		return -1;
	}
	//非空,出队
	//临时指针
	node_t* tmp = queue->front;
	queue->front = tmp->next;
	if (val) {
		*val = tmp->val;
	}
	free(tmp);
	queue->count--;
	//如果删除的是最后一个元素，则rear可能变为野指针
	if (queue->front == NULL) {
		queue->rear = NULL;
	}

	return 0;
}
```

`LinkQueue`:

```java
package com.Sonnet.LinkQueue;

import com.Sonnet.Element.Element;

public class LinkQueue {
    //节点结构
    private class Node {
        Element element;
        Node next;

        public Node() {}
        public Node(Element element) {
            this.element = element;
        }
        public Node(Element element, Node next) {
            this.element = element;
            this.next = next;
        }
    }

    int count;
    Node front;
    Node rear;

    public LinkQueue() {
        this.count = 0;
        this.front = null;
        this.rear = null;
    }

    /*
        功能： 入队
        参数： 需要入队的元素
        返回值： 成功true 失败false
     */
    public boolean enLinkQueue(Element element) {
        if (element == null) {
            return false;
        }
        //创建新节点
        Node node = new Node(element, null);
        //第一次入队
        if (this.front == null) {
            this.front = node;
            this.rear = node;
        } else {
            this.rear.next = node;
            this.rear = node;
        }
        this.count++;

        return true;
    }

    /*
        功能： 出队
        参数： 无
        返回值： 出队的元素
     */
    public Element deLinkQueue() {
        //空
        if (this.front == null) {
            System.out.println("empty");
            return null;
        }
        //临时保存
        Element tmp = this.front.element;
        Node oldNode = this.front;
        //出队
        this.front = oldNode.next;
        this.count--;
        oldNode.element = null;
        oldNode.next = null;
        // 最后一个元素出队
        if (this.front == null) {
            this.rear = null;
        }

        return tmp;
    }

    /*
        功能： 清理队列
        参数： 无
        返回值： 无
     */
    public void clearLinkQueue() {
        //临时指针
        Node tmp;
        while (this.front != null) {
            tmp = this.front;
            this.front = tmp.next;
            this.count--;
            tmp.next = null;
            tmp.element = null;
        }
        this.rear = null;
    }
}
```
