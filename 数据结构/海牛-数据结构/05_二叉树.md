# 05_二叉树

* 结点： 使用树结构存储的每一个数据元素都称为结点。
* 根结点：有一个特殊的结点，这个结点没有前驱，我们将这种结点称之为根结点。
* 父结点（双亲结点）、子结点和兄弟结点：如果一个节点指向另一个节点，那么被指向的节点就是其父结点。如果一个节点被另一个节点指向，那么这个被指向的节点就是其子结点。拥有同一个父结点的节点互为兄弟结点。
* 叶子结点：如果一个结点没有任何子结点，那么此结点就称之为叶子结点。
* 结点的度：结点拥有子叶的个数，就称之为结点的度。
* 树的度：在各个结点当中，度的最大值，为树的度。
* 树的深度或者高度：结点的层次从根结点开始定义起，根为第一层，根的孩子为第二层，以此类推。

## 5.5 遍历

### 5.5.1 广度优先遍历

用队列实现，层次遍历，激活一个节点，就可能产生2个新任务，引入缓存区查看任务， 不断从缓存区中获取任务。

<font color = "blue"> c 实现： </font>

```c
/*广度优先遍历*/
#define MAX_QUEUE_SIZE 10
void levelOrderBinaryTree(BinaryTree_t* tree) {
	//创建队列
	TreeNode_t* queue[MAX_QUEUE_SIZE];
	int front = -1;
	int rear = -1;
	//预激活队列
	queue[0] = tree->root;
	front = 0;
	rear = 1;
	TreeNode_t* node;
	printf("levelOrder:\n");
	while (front != rear) {
		//出队
		node = queue[front];
		printf("%c\t", node->data);
		front = (front + 1) % MAX_QUEUE_SIZE;
		//入队
		if (node->left) {
			if ((rear + 1) % MAX_QUEUE_SIZE == front) {
				printf("overflow\n");
				return;
			}
			queue[rear] = node->left;
			rear = (rear + 1) % MAX_QUEUE_SIZE;
		}
		if (node->right) {
			if ((rear + 1) % MAX_QUEUE_SIZE == front) {
				printf("overflow\n");
				return;
			}
			queue[rear] = node->right;
			rear = (rear + 1) % MAX_QUEUE_SIZE;
		}
	}
	printf("\n");
}
```

### 5.5.5 先序非递归

递归变为非递归，需要引入一个栈，这个栈仅仅在函数的局部使用。引入一个栈，每激活一个结点，它的左右任务按照先序顺序保存到记忆栈，先右后左放入记忆栈。出栈，出一个，激活一个新的任务，又重复，先右后左放入栈，当栈内没有元素时，整个遍历就结束。

<font color = "blue"> c 实现：</font>

```c
/*先序非递归*/
#define MAX_STACK_SIZE 10
void preOrderBinaryTreeNoRecur(BinaryTree_t* tree) {
	//申请栈满递增栈
	TreeNode_t* stack[MAX_STACK_SIZE];
	int top = -1;
	//预激活，放入第一个任务
	stack[++top] = tree->root;
	TreeNode_t* node;
	printf("preOrderNoRecur:\n");
	while (top >= 0) {
		//出栈
		node = stack[top--];
		showTreeNode(node);
		//入栈
		if (node->right) {
			stack[++top] = node->right;
		}
		if (node->left) {
			stack[++top] = node->left;
		}
	}
	printf("\n");
}
```



<font color = "blue"> Java 实现：</font>

```java

	功能： 先序非递归
    参数： 无
    返回值： 无

public void preOrderBinaryTreeNoRecur() {
```

### 5.5.6 中序非递归

中序非递归，引入一个栈，以根结点开始，先整条左边入栈。出栈访问，这个结点的右孩子作为新结点，左边入栈。

<font color = "blue"> c 实现： </font>

```c
/*中序非递归*/
void inOrderBinaryTreeNoRecur(BinaryTree_t* tree) {
	//申请栈
	TreeNode_t* stack[MAX_STACK_SIZE];
	int top = -1;
	//预激活
	printf("inOrderNoRecur:\n");
	TreeNode_t* node = tree->root;
	while (top >= 0 || node) {
		if (node) {
			stack[++top] = node;
			node = node->left;
		}
		else {
			node = stack[top--];
			showTreeNode(node);
			node = node->right;
		}
	}
	printf("\n");
}
```

```c
//层次遍历，激活一个节点，就可能产生2个新任务，引入缓存区
//查看任务， 不断从缓存区中获取任务
#define MAX_QUEUE_SIZE 8
void levelOrderBinaryTree(BinaryTree_t* tree) {
	//申请一个队列结构，放到栈上，层次遍历后，自动清除
	TreeNode_t* queue[MAX_QUEUE_SIZE];
	int front = 0;
	int rear = 0;
	//预激活队列
	queue[rear] = tree->root;
	rear = (rear + 1) % MAX_QUEUE_SIZE;
	//不断出队列，每出一个元素，就访问，执行访问逻辑，直到队列为空
	TreeNode_t* node;
	printf("level:\n");
	while (front != rear) {
		//出队一个元素，执行一个任务
		node = queue[front];
		front = (front + 1) % MAX_QUEUE_SIZE;
		//访问这个节点，再发现新任务
		visitTreeNode(node);
		if (node->left) {
			queue[rear] = node->left;
			rear = (rear + 1) % MAX_QUEUE_SIZE;
		}
		if (node->right) {
			queue[rear] = node->right;
			rear = (rear + 1) % MAX_QUEUE_SIZE;
		}
	}
	printf("\n");
}

static void destroyNode(BinaryTree_t* tree, TreeNode_t* node) {
	if (node == NULL) return;
	destroyNode(tree, node->left);
	destroyNode(tree, node->right);
	free(node);
	tree->num--;
}
```

```java
    private static final int MAX_QUEUE_SIZE = 10;
    public void levelOrderBinaryTree() {
        //创建队列
        TreeNode[] queue = new TreeNode[MAX_QUEUE_SIZE];
        int front = 0;
        int rear = -1;
        //预激活
        queue[0] = this.root;
        rear = 1;
        TreeNode node;
        System.out.println("levelOrder:");
        //当队列为空时，停止
        while (front != rear) {
            //出队
            node = queue[front];
            this.visitTreeNode(node);
            front = (front + 1) % MAX_QUEUE_SIZE;
            //入队
            if (node.left != null) {
                if ((rear + 1) % MAX_QUEUE_SIZE == front) {
                    System.out.println("overflow");
                    return;
                }
                queue[rear] = node.left;
                rear = (rear + 1) % MAX_QUEUE_SIZE;
            }
            if (node.right != null) {
                if ((rear + 1) % MAX_QUEUE_SIZE == front) {
                    System.out.println("overflow");
                    return;
                }
                queue[rear] = node.right;
                rear = (rear + 1) % MAX_QUEUE_SIZE;
            }
        }
        System.out.println();
    }
```
