# 01_顺序表

顺序表操作简单，但要进行多次删除和插入时需要大量操作



## 1.1 顺序表结构的申明

<font color = "blue">C实现：</font>

```c
typedef int Element_t;

typedef struct {
	Element_t* data;
	int pos;
	int capacity;
} SEQTable_t;
```

* 其中`Element_t`是需要元素的类型

* `SEQTable_t`是顺序表结构的类型
  *  `data`是指向在堆中开辟的一个空间的指针，用来存储需要的元素
  * `pos`是当前的位置，初始时为0，当添加一个元素之后，`pos`就指向1，同时`pos`还可以表示当前元素的数量，当前添加一个元素之后，索引0的位置被添加，`pos`则变为1
  * `capacity`则是顺序表的最大容量，同时也可以表示顺序表的临界值



<font color = "blue">Java实现：</font>

可以在创建一个`Element`类来表示需要添加的元素类型,这里就用int表示(懒得改了)

```java
public class SEQTable {
    public int[] data;
    int pos;
    int capacity;
}
```



## 1.2 顺序表的创建

<font color = "blue">C实现：</font>

首先要使用`malloc`函数在堆上开辟一个空间来储存`SEQTable_t`的指针，因为又可能开辟失败，所以需要进行判断，如果开辟失败则要返回NULL，如果开辟成功则需要对这个顺序表的内部进行初始化。在内部进行初始化时，通过传入的参数n，来确定需要开辟元素的个数，因此只需要开辟`malloc(sizeof(Element_t) * n)`就可以了，既然知道了开辟的个数，`capacity`的大小也就是n，又现在只是进行创建，还没有插入任何的元素，所以`pos`为0。

```c
/*
	功能： 创建顺序表，并且进行初始化
	参数： 需要的元素个数
	返回值： 创建完成的顺序表指针, 如果失败则返回空
		1. 开辟顺序表空间
		2. 判断是否开辟成功
		3. 开辟成功对顺序表进行初始化
*/
SEQTable_t* creatSeqTable(int n) {
	SEQTable_t* table = malloc(sizeof(SEQTable_t));
	//如果空间开辟失败
	if (table == NULL) {
		printf("table malloc failed\n");
        free(table);
		return NULL;
	}

	//开辟成功进行初始化
	table->data = malloc(sizeof(Element_t) * n);
	if (table->data == NULL) {
		printf("data malloc failed\n");
		return NULL;
	}
	table->pos = 0;
	table->capacity = n;

	return table;
}

```



<font color = "blue">Java实现：</font>

对于Java而言开辟空间只需要`new`一个`SEQTable`就可以了，而初始化则可以通过构造函数来实现

```java
    /*
        功能：初始化顺序表
        参数：需要的元素个数
     */ 
	public SEQTable( int n) {
        this.data = new int[n];
        this.pos = 0;
        this.capacity = n;
    }

```



## 1.3 打印顺序表内容

对于打印顺序表只需要遍历就行



<font color = "blue"> C 实现：</font>

```c
/*
	功能： 打印顺序表中的信息
	参数： 需要打印的顺序表的指针
	返回值： 无
			1. 判断该顺序表中是否有元素，没有元素则进行提示
			2. 遍历打印
*/
void showSeqTable(const SEQTable_t* table) {
	if (table->pos == 0) {
		printf("data is null\n");
		return;
	}
	printf("pos is %d and capacity is %d\n", table->pos, table->capacity);
	for (int i = 0; i < table->pos; i++) {
		printf("%d ", table->data[i]);
	}
	printf("\n");
	return;
}

```

>由于只是进行遍历打印， 并不会对顺序表中的内容进行改变，因此可以在形参中添加`const`标识符

## 1.4 尾插法添加元素

因为`pos`是表示的就是当前元素的位置，所以只需要在索引等于`pos`的位置上直接添加就行，由于添加了元素，因此`pos`需要后移。需要注意的是在堆上开辟的`data`空间是有限的，因此当`pos == capacity`时需要进行扩容操作。



<font color = "blue">C 实现：</font>

```c
/*
	功能： 尾插法添加元素
	参数： 需要进行操作的顺序表指针 ， 需要添加的元素
	返回值： 成功0 失败-1
		1. 判断空间是否存在，防止小人
		2. 判断是否需要进行扩容操作
		3. 尾插
*/
int pushbcakSeqTable(SEQTable_t* table, Element_t value) {
	//判断空间是否存在
	if (table == NULL || table->data == NULL) {
		printf("table is null\n");
		return -1;
	}
	//判断扩容
	if (table->pos == table->capacity && enlargeSeqTable(table)) {
		return -1;
	}
	//尾插
	table->data[table->pos++] = value;

	return 0;
}

```

>`(table->pos == table->capacity && enlargeSeqTable(table))`
>
>如果`pos == capacity`，那么执行`enlargeSeqTable(table)`函数
>
>对于这段代码，可以理解为if嵌套：
>
>```c
>if (table->pos == table->capacity) {
>    if (enlargeSeqTable(table)) {
>        return -1;
>    }
>}
>```
>
>首先指向&&前的内容，如果返回值为0，则不会执行&&后的内容，直接进行尾插操作；如果返回值为非0，则执行&&后的内容。
>
>当容量满了之后进行扩容操作，如果扩容失败，返回-1，执行if里的内容。
>
>Java同理



<font color = "blue"> Java 实现：</font>

```java
    /*
        功能：尾插
        参数：需要插入的元素
        返回值：成功true ， 失败false
            1. 判断是否需要扩容
            2. 尾插
     */
    public boolean pushbackSeqTable(int value) {
        if (this.pos == this.capacity) {
            this.enlargerSeqTable();
        }
        this.data[pos++] = value;

        return true;
    }

```

> 因为只有new了之后才可以调用方法，因此不需要判断空间是否存在



## 1.5 任意位置插入元素

并不建议使用任意位置插入元素，需要移动大量的元素， 时间复杂度高。

判断是否需要扩容，将需要插入的索引空间上的元素和之后的元素都后移一位，为新元素腾出位置，插入新元素。



<font color = "blue"> C 实现： </font>

```c
/*
	功能： 任意位置插入元素
	参数： 需要进行操作的顺序表指针 需要插入位置的索引 需要插入的元素
	返回值： 成功0 失败-1
		1. 判断顺序表是否存在
		2. 索引是否合法 
		3. 判断是否需要扩容
		4. 将索引上的空间和之后的空间都后移一位，为新元素腾空间
*/
int insertSeqTable(SEQTable_t* table, int index, int value) {
	// 判断空间有效性
	if (table == NULL || table->data == NULL) {
		printf("table is null\n");
		return -1;
	}
	// 判断索引合法
	if (index < 0 || index > table->pos) {
		printf("index invalid\n");
		return -1;
	}
	//是否扩容
	if (table->pos == table->capacity && enlargeSeqTable(table)) {
		printf("enlarge malloc failed\n");
		return -1;
	}
	//插入
	for (int i = table->pos - 1; i >= index; i--) {
		table->data[i + 1] = table->data[i];
	}
	table->data[index] = value;
	table->pos++;

	return 0;
}
```



<font color = "blue"> Java 实现：</font>

```java
/*
    功能： 任意位置添加元素
    参数： 需要添加的索引位置 需要添加的元素
    返回值： 成功true 失败false
        1. 索引合法性
        2. 是否扩容
        3. 插入
 */
    public boolean insertSeqTable(int index, int value) {
        if (index < 0 || index >= this.pos) {
            System.out.println("index invalid");
            return false;
        }
        if (this.pos == this.capacity ) {
            this.enlargerSeqTable();
        }
        for (int i = this.pos - 1; i >= index; i--) {
            this.data[i + 1] = this.data[i];
        }
        this.data[index] = value;
        this.pos++;

        return true;
    }

```





## 1.6 顺序表扩容

对于扩容操作，需要在堆上重新开辟一个空间，一般这个空间为之前空间的2倍。因为如果扩容空间太小，之后每次进行插入操作都需要扩容，很浪费资源。之后，将老空间中的元素拷贝到新空间。然后就可以释放空间，让data指针指向新空间就可以了。需要注意的是，在c语言中需要手动`free`，而Java有`gc`机制可以自动回收。



<font color = "blue"> C 实现：</font>

```c
/*
	功能： 顺序表扩容
	参数： 需要扩容的顺序表指针
	返回值： 成功0 失败-1
		1. 开辟新的空间
		2. 将老空间中的元素拷贝到新空间
		3. free
		4. data指针指向新空间

*/
int enlargeSeqTable(SEQTable_t* table) {
	//开辟新空间
	Element_t* tmp = malloc(sizeof(Element_t) * table->capacity * 2);
	if (tmp == NULL) {
		printf("enlargeSeqTable malloc failed\n");
		return -1;
	}
	//拷贝
	memcpy(tmp, table->data, sizeof(Element_t) * table->pos);
	table->capacity *= 2;
	//释放空间，让data指向新空间
	free(table->data);
	table->data = tmp;

	return 0;
}

```



<font color = "blue"> Java 实现: </font>

```java
	/*
        功能： 顺序表扩容
        参数： 无
        返回值： 成功true 失败false
            1. 开辟新空间
            2. 将老空间中的元素拷贝到新空间中
            3. 让data指针指向新空间
     */
    public boolean enlargerSeqTable() {
        int[] tmp = new int[capacity * 2];
        System.arraycopy(this.data, 0, tmp, 0, capacity);
        this.data = tmp;
        this.capacity *= 2;

        return true;
    }


```

> 对于`System.arrayCopy`:
>
> `public static void arraycopy(Object src, int srcPos, Object dest, int destPos, int length);	//数组拷贝，（数据资源组， 起始索引， 目的地数组， 起始索引， 拷贝个数）`



> 对于c和Java的拷贝代码都可以不调用函数和方法直接遍历赋值就可以实现



## 1.7 顺序表查找

遍历顺序表， 如果找到需要的元素就返回对应的索引；如果没有找到就返回-1。



<font color = "blue"> C实现：</font>

```c
/*
	功能： 查找对应元素的索引
	参数： 需要进行操作的顺序表指针 需要查找的元素
	返回值： 如果查找成功返回对应的索引 ，查找失败则返回-1
		1. 遍历
*/
int findIndexOfSeqTable(const SEQTable_t* table, Element_t value) {
	int index = -1;
	for (int i = 0; i < table->pos; i++) {
		if (table->data[i] == value) {
			index = i;
			return index;
		}
	}
	printf("not found index\n");

	return -1;
}

```



<font color = "blue"> Javas实现 :</font>

```java
    /*
        功能： 查找对应元素的索引
        参数： 需要查找的元素
        返回值： 对应元素的索引值， 如果没找到则返回-1
     */
    public int findIndexOfSeqTable(int value) {
        int index = -1;
        for (int i = 0; i < this.pos; i++) {
            if (value == this.data[i]) {
                index = i;
                return index;
            }
        }
        System.out.println("not found index");
        return -1;
    }

```



## 1.8 顺序表删除

遍历整个顺序表找到需要删除的元素索引，通过遍历将该索引之后的元素都向前移动一位



<font color = "blue"> C实现: </font>

```c
/*
	功能： 顺序表的删除
	参数： 需要进行操作的顺序表指针 删除的元素
	返回值： 成功0 失败-1
		1. 查找索引，失败返回-1
		2. 删除
*/
int deleteSeqTable(SEQTable_t* table, Element_t value) {
	//获得索引
	int index = findIndexOfSeqTable(table, value);
	if (index == -1) return -1;
	for (int i = index + 1; i < table->pos; i++) {
		table->data[i - 1] = table->data[i];
	}
	table->pos--;

	return 0;
}

```



<font color = "blue"> Java实现: </font>

```java
    /*
        功能： 顺序表的删除
        参数： 需要删除的元素
        返回值： 成功true 失败false
            1. 获得需要删除元素的索引
            2. 删除
     */
    public boolean deleteSeqTable(int value) {
        int index = this.findIndexOfSeqTable(value);
        if (index == -1) {
            return false;
        }
        for (int i = index + 1; i < this.pos; i++) {
            this.data[i - 1] = this.data[i];
        }
        this.pos--;
        
        return true;
    }

```



## 1.9 修改顺序表的元素

遍历数组，找到需要修改元素的索引值，对旧元素进行重新赋值



<font color = "blue"> C 实现：</font>

```c
/*
	功能： 修改顺序表元素
	参数： 需要修改的顺序表指针 旧元素 新元素
	返回值： 成功0 失败-1
		1. 找到旧元素的索引，失败返回-1
		2. 重新赋值
*/
int setSeqTable(SEQTable_t* table, Element_t old, Element_t value) {
	int index = findIndexOfSeqTable(table, old);
	if (index == -1) {
		return -1;
	}
	table->data[index] = value;

	return 0;
}
```

```java
            2. 对旧元素进行修改
```

## 1.10 释放顺序表

由于Java中有`gc`机制，因此不需要考虑释放方法，而在c语言中，我们需要手动`free`。



<font color = "blue"> C 实现：</font>

```c
/*
	功能： 释放顺序表
	参数： 需要释放的顺序表指针
	返回值： 无
*/
void releaseSeqTable(SEQTable_t* table) {
	if (table && table->data != NULL) {
		free(table->data);
	}
	free(table);
}

```

> 不建议在main函数中直接free，这种设计模式并不好，我们是通过调用设计者的方法来创建的顺序表指针，那么也应该调用设计者设计的方法来释放顺序表指针



## 1.11 完整实现

<font color = "blue"> C 实现：</font>

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

//顺序表结构申明
typedef int Element_t;	//一个指向元素的类型

//定义顺序表的表头结构
typedef struct {
	Element_t *data;	//存储表空间的首地址
	int pos;			//指向表空间中待插入位置的索引号
	int capacity;		//顺序表的最大容量，一旦超过就触发扩容操作
} SEQTable_t;

//函数接口的实现
/*
	形参：有n个元素
	返回值：顺序表指针
	功能：创建一个顺序表
		1. 创建空间
		2. 进行初始化
*/
SEQTable_t* creatSeqTable(int n) {
	//创建空间
	SEQTable_t* table = malloc(sizeof(SEQTable_t));
	//如果申请失败就报错
	if (table == NULL) {
		printf("createSeqTable malloc failed\n");
		free(table);
        return NULL;
	}

	//创建成功之后，进行初始化
	//因为有n个元素，所以需要开辟 sizeof(Element_t) * n 的空间
	table->data = malloc(sizeof(Element_t) * n);
	//同理，开辟失败
	if (table->data == NULL) {
		printf("table->data malloc failed\n");
		return NULL;
	}
	//因为需要n个元素，所以需要申请n个空间
	//同时第n个元素的索引为n - 1，因此也可以将n作为临界值
	table->capacity = n;
	//因为现在还没有进行插入元素，因此pos当前位置为0
	//同时pos也可以表示当前元素的个数，当插入一个元素时，元素索引为0，pos指向1
	table->pos = 0;

	//返回顺序表指针
	return table;
}

/*
	功能：查找顺序表中的元素
	参数：需要进行操作的顺序表指针 和 需要查找的元素
	返回值：成功返回索引 失败返回-1
*/
int findSeqTable(const SEQTable_t* table, Element_t value) {
	int index = -1;
	for (int i = 0; i < table->pos; i++) {
		if (value == table->data[i]) {
			index = i;
		}
	}
	
	return index;
}


/*
	功能：顺序表扩容
	参数：需要进行扩容的循序表指针
	返回值：0成功 -1失败
	(可以使用recalloc)
		1. 再申请一个更大的空间
		2. 拷贝老空间中的内容到新空间中
		3. 释放老空间，让表头里的data指向新空间
*/
static int enlargeTable(SEQTable_t* table) {
	// 1. 再申请一个更大的空间
	// 不建议每次只扩容一个空间，不然每次添加都需要在调用函数，浪费时间，可以进行2倍扩容
	Element_t* tmp = malloc(sizeof(Element_t) * table->capacity * 2);
	if (tmp == NULL) {
		printf("enlargeTable malloc failed\n");
		return -1;
	}
	// 2. 拷贝老空间里的内容到新空间
	memcpy(tmp, table->data, sizeof(Element_t) * table->pos);
	table->capacity *= 2;
	// 3. 释放老空间，让表头里的data指向新空间,顺序不能错
	free(table->data);
	table->data = tmp;

	return 0;
}

/*
	形参：需要进行操作的顺序表指针 和 需要添加的元素
	返回值：0成功 -1失败
	功能：尾插法，在尾部添加元素
		1. 判断空间是否存在
		2. 空间是否满，如果满需要进行扩容
		3. 添加元素
*/
int pushbackSeqTable(SEQTable_t* table, Element_t value) {
	//防小人：
	//1. 空间根本不存在
	if (table == NULL || table->data == NULL) {
		printf("table is null\n");
		return -1;
	}
	//2. 空间已经满了，再插入就溢出, 需要扩容
	// 如果空间已经满了，那么进行扩容扩容操作，并且扩容失败则报错
	if (table->pos >= table->capacity && enlargeTable(table)) {
		return -1;
	}
	// 添加元素，并且让pos++
	table->data[table->pos] = value;
	table->pos++;

	return 0;
}

/*
	功能：任意位置插入元素, 慎用
	参数：需要进行操作的顺序表指针 要插入的索引 和 需要插入的元素
	返回值：成功0 失败-1
		1. 判断空间有效性
		2. 索引是否合法
		3. 是否扩容
		4. 搬移数据为新数据腾出位置， 向后挪动
*/
int insertPosSeqTable(SEQTable_t* table, int index, Element_t value) {
	//空间有效性
	if (table == NULL || table->data == NULL) return -1;
	if (index < 0 || index > table->pos) {
		printf("index invalid\n");

	}
	//是否扩容
	if (table->pos == table->capacity && enlargeTable(table)) {
		return -1;
	}
	//插入
	for (int i = table->pos - 1; i >= index; i--) {
		table->data[i + 1] = table->data[i];
	}
	table->data[index] = value;
	table->pos++;

	return 0;
}

/*
	功能：删除顺序表
	参数：需要操作的顺序表指针 和 需要删除的元素
	返回值：成功0 失败-1
		1. 查找value在table中的索引号
		2. 删除元素， 从后往前覆盖
*/
int deletSeqTable(SEQTable_t* table, Element_t value) {
	// 1. 查找value在table中的索引号
	int index = findSeqTable(table, value);
	if (index == -1) {
		printf("not found value\n");
		return -1;
	}
	// 2. 删除元素
	for (int i = index + 1; i < table->capacity; i++) {
		table->data[i - 1] = table->data[i];
	}
	table->pos--;

	return 0;
}

	参数：顺序表
	返回值：无
*/
void showSeqTable(const SEQTable_t* table) {

		printf("%d ", table->data[i]);
	}
	printf("\n");

void releaseSeqTable(const SEQTable_t* table) {
	//必要要table存在
	if (table) {
		if (table->data != NULL) {
			//不可以直接free（table）,一次malloc就应该一次free
			free(table->data);
		}
		free(table);
	}
}

		2. 重新赋值
*/

	int index = findIndexOfSeqTable(table, old);
	if (index == -1) {
		return -1;
	}
	table->data[index] = value;
```

```java
        功能：初始化顺序表

     */
    public SEQTable( int n) {

    }

        功能： 打印顺序表中的信息
        参数： 无
        返回值： 无
            1. 判断该顺序表中是否有元素，没有元素则进行提示
            2. 遍历打印
     */
    public void showSeqTable() {
        if (this.pos == 0) {
            System.out.println("data is null");
            return;
        }
        System.out.println("pos is " + this.pos + " and capacity is " + this.capacity);
        for (int i = 0 ; i < this.pos; i++) {
            System.out.print(this.data[i] + " ");
        }
        System.out.println();
    }

    /*
        功能：尾插
        参数：需要插入的元素
        返回值：成功true ， 失败false
            1. 判断是否需要扩容
            2. 尾插
     */
    public boolean pushbackSeqTable(int value) {
        if (this.pos == this.capacity) {
            this.enlargerSeqTable();
        }
        this.data[pos++] = value;

        return true;
    }

    /*
        功能： 顺序表扩容
        参数： 无
        返回值： 成功true 失败false
            1. 开辟新空间
            2. 将老空间中的元素拷贝到新空间中
            3. 让data指针指向新空间
     */
    public boolean enlargerSeqTable2() {
        int[] tmp = new int[capacity * 2];
        for (int i = 0; i < this.capacity; i++) {
            tmp[i] = this.data[i];
        }
        this.data = tmp;
        this.capacity *= 2;

        return true;
    }

        /*
        功能： 顺序表扩容
        参数： 无
        返回值： 成功true 失败false

    public boolean enlargerSeqTable() {

        System.arraycopy(this.data, 0, tmp, 0, capacity);
        this.data = tmp;
        this.capacity *= 2;

        return true;

    public int findIndexOfSeqTable(int value) {
        int index = 0;
        for (int i = 0; i < this.pos; i++) {
            if (value == this.data[i]) {
                index = i;
                return index;
            }
        }
        System.out.println("not found index");
        return -1;
    }

        功能： 顺序表的删除
        参数： 需要删除的元素
        返回值： 成功true 失败false
            1. 获得需要删除元素的索引
            2. 删除
     */
    public boolean deleteSeqTable(int value) {
        int index = this.findIndexOfSeqTable(value);
        if (index == -1) {
            return false;
        }
        for (int i = index + 1; i < this.pos; i++) {
            this.data[i - 1] = this.data[i];
        }
        this.pos--;

        return true;
    }

    功能： 任意位置添加元素
    参数： 需要添加的索引位置 需要添加的元素
    返回值： 成功true 失败false
        1. 索引合法性
        2. 是否扩容
        3. 插入
 */
    public boolean insertSeqTable(int index, int value) {
        if (index < 0 || index >= this.capacity) {
            System.out.println("index invalid");
            return false;
        }
        if (this.pos == this.capacity ) {
            this.enlargerSeqTable();
        }
        for (int i = this.pos - 1; i >= index; i--) {
            this.data[i + 1] = this.data[i];
        }
        this.data[index] = value;
        this.pos++;

        return true;
    }

    /*
        功能： 修改顺序表中的元素
        参数： 旧元素 新元素
        返回值： 成功true 失败false
            1. 获得需要修改元素的索引
            2. 对旧元素进行修改
     */
    public boolean setSeqTable(int old, int value) {
        int index = this.findIndexOfSeqTable(old);
        if (index == -1) return false;
        this.data[index] = value;

        return true;
    }
```
