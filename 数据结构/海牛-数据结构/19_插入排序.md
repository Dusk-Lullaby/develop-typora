# 插入排序

## 1. 概念

**插入排序**是所有排序方法中最简单的一种算法，其主要的实现思想是将数据按照一定的顺序一个一个的插入到有序的表中，最终得到的序列就是已经排序好的数据。

**优点**

- **极佳的局部有序适应性 (Adaptive)**：**当输入数据已经部分有序，或者只有少量元素错位时，插入排序的效率极高。**在最好情况下（数组完全有序），只需进行 n-1 次比较，无需移动元素，时间复杂度降至 O(n)。
- **小规模数据常数极小**：虽然它的渐进时间复杂度较高，但其内部循环非常紧凑，常数因子很小。对于小规模数据集（通常 n < 50），它的实际运行速度往往快于快速排序或归并排序。
- **空间复杂度极低 (In-place)**：它是一种原地排序算法，只需要一个额外的临时变量（即 `tmp` 或 `temp`）来存储当前需要插入的元素，空间复杂度为 O(1)。
- **稳定性 (Stable)**：在插入过程中，如果遇到相等的元素，可以将新元素插在相等元素的后面，从而保证相等元素的相对顺序不发生改变。这在多关键字排序中非常重要。
- **支持在线排序**：它可以处理流式数据，即在接收数据的同时进行排序，而不需要等所有数据就绪。

**缺点**

- **大规模数据效率极低**：其平均和最坏时间复杂度均为 O(n^2)。当数据量增大时，时间消耗呈平方级增长，完全无法胜任大规模无序数据的排序任务。
- **频繁的内存写操作**：在数组（顺序表）中插入元素时，如果目标位置靠前，需要将该位置之后的所有已排序元素向后移动一位。这种大量的内存移动（覆盖）操作在元素体积较大或数据量较多时会导致严重的性能损耗。





**希尔排序（Shell Sort）**是计算机科学历史上第一批突破 `O(n2)`时间复杂度的排序算法之一。它的核心设计理念是对插入排序的局限性进行针对性优化。

希尔排序通过引入**增量（Gap）**的概念，将原本连续的数组从逻辑上划分为多个子序列。

**执行步骤：**

1. **确定初始增量**：通常取数组长度的一半，即 *gap*=*n*/2。
2. **分组排序**：将所有距离为 *gap* 的元素归为一组，对这些分组分别进行插入排序。由于跨度大，元素可以一次性跳跃多个位置，迅速将较小的值移到数组前端。
3. **缩小增量**：缩小 *gap* 的值（例如 *gap*=*gap*/2），此时分组变少，每组包含的元素变多。再次对各个分组进行插入排序。
4. **最终微调**：当 *gap*=1 时，整个数组被视为一个分组，执行最后一次标准的插入排序。此时数组已经处于“基本有序”状态，插入排序的效率达到最高。



- **时间复杂度**：高度依赖于增量序列的选择。
  - **希尔原始增量**（每次除以 2）：最坏时间复杂度仍为 `O(n2)`。
  - **`Hibbard` 增量**（`2k−1`）：最坏时间复杂度优化至 `O(n1.5)`。
  - **Knuth 增量**（`3k−1)/2`）：平均时间复杂度约为 `O(n1.25)` 到 `O(n1.3)`。
- **空间复杂度**：*O*(1)。只需要常数级别的额外空间用于元素交换（如 `temp` 变量），属于原地排序（In-place）。
- **稳定性**：**不稳定**。在跨越 gap 进行比较和交换时，相同元素的相对顺序可能会被打破。



## 2. 插入排序

<font color = "blue"> C 实现：</font>

```c
void insertSort1(int* table, int n) {
	for (int i = 1; i < n; i++) {
		// 如果后面的数比前面的数小
		if (table[i] < table[i - 1]) {
			// 存储需要插入的数据
			int tmp = table[i];
			// 用j的辅助变量找到待插入的位置
			int j = i - 1;
			while (j >= 0 && tmp < table[j]) {
				table[j + 1] = table[j];
				j--;
			}
			table[j + 1] = tmp;
		}
	}
}

void insertSort2(int* table, int n) {
	for (int i = 1; i < n; i++) {
		int tmp = table[i];
		int j;
		for (j = i; j > 0 && tmp < table[j - 1]; j--) {
			table[j] = table[j - 1];
		}
		table[j] = tmp;
	}
}

```

## 3. 希尔排序

<font color = "blue"> C 实现：</font>

```c
void shellSort(int* table, int n) {
	for (int gap = n / 2; gap > 0; gap /= 2) {
		for (int i = gap; i < n; i++) {
			int tmp = table[i];
			int j;
			for (j = i; j >= gap && tmp < table[j - gap]; j -= gap) {
				table[j] = table[j - gap];
			}
			table[j] = tmp;
		}
	}
}
```

`insertSort.c`

```c
#include <stdio.h>
#include <stdlib.h>
#include "insertSort.h"

void insertSort(int* table, int n) {
	// 从第二个元素开始插入排序
	for (int i = 1; i < n; i++) {
		if (table[i] < table[i - 1]) {
			// 用j的辅助变量找到待插入的位置
			int j = i - 1;
			int temp = table[i];
			// 查找索引为[0...i-1]的位置
			while (j > -1 && temp < table[j]) {
				table[j + 1] = table[j];
				j--;
			}
			table[j + 1] = temp;
		}
	}
}

void insertSortV1(int* table, int n) {
	for (int i = 1; i < n; i++) {
		int e = table[i];
		int j;
		for (j = i; j > 0 && e < table[j - 1]; j--) {
			table[j] = table[j - 1];
		}
		table[j] = e;
	}
}

void shellSort(int* table, int n) {
	// 按照gap分组
	for (int gap = n / 2; gap > 0; gap /= 2) {
		for (int i = gap; i < n; i++) {
			int e = table[i];
			int j;
			for (j = i; j >= gap && e < table[j - gap]; j -= gap) {
				table[j] = table[j - gap];
			}
			table[j] = e;
		}
	}
}
```

```c
#include <stdio.h>
#include <stdlib.h>
#include "insertSort.h"

int main() {
	// 初始化随机数种子
	srand((unsigned int)time(NULL));
	int n = 10;
	int* table = malloc(sizeof(int) * n);
	int* table2 = malloc(sizeof(int) * n);
	int* table3 = malloc(sizeof(int) * n);
	if (table == NULL || table2 == NULL || table3 == NULL) return;
	for (int i = 0; i < n; i++) {
		table[i] = rand() % 100 + 1;
		printf("%d\t", table[i]);
	}
	insertSort(table, n);
	printf("\n");
	for (int i = 0; i < n; i++) {
		printf("%d\t", table[i]);
	}
	printf("\n");

	for (int i = 0; i < n; i++) {
		table2[i] = rand() % 100 + 1;
		printf("%d\t", table2[i]);
	}
	insertSortV1(table2, n);
	printf("\n");
	for (int i = 0; i < n; i++) {
		printf("%d\t", table2[i]);
	}
	printf("\n");

	for (int i = 0; i < n; i++) {
		table3[i] = rand() % 100 + 1;
		printf("%d\t", table3[i]);
	}
	shellSort(table3, n);
	printf("\n");
	for (int i = 0; i < n; i++) {
		printf("%d\t", table3[i]);
	}
	printf("\n");

	free(table);
	free(table2);
	free(table3);

	return 0;
}
```
