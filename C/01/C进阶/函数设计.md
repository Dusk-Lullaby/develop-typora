# 函数设计

## 函数的本质

* 函数名
  * 程序员编写代码的空间的名称，本质就是一个地址（常量）
  * `int fun(int a, int b);` 就是声明了一个地址常量
  * `fun(10, 20)` 使用这个地址，访问代码空间



## 函数交换2个数案例分析



* 那么函数如何获取信息呢？

  * **答案是通过拷贝**
  * 是从调用者处拷贝到函数空间
  * 也就是将实参拷贝到形参中

* 案例：交换函数

  * 设计一个函数可以让a与b的值进行交换

  * ```c
    #include <stdio.h>
    
    int main() {
    	int a = 20;
    	int b = 30;
    
    	printf("a is %d, b is %d\n", a, b);
    
    	return 0;
    }
    ```

  * 因为要让a和b来进行交换，因此需要将a和b传给函数，因此可以设计为`myswap(int , int )` ,但是我需要在函数空间交换这两个值，因此需要两个变量来接收，`myswap(int a, int b)` , 只是进行交换，不需要进行返回，返回值为void，函数就设计好了`void myswap(int a, int b){}`,具体的交换逻辑，可以通过一个变量temp来临时储存。

    * ```c
      void myswap(int a, int b) {
      	int temp;
      	temp = a;
      	a = b;
      	b = temp;
      	printf("a is %d, b is %d\n", a, b);
      }
      
      #include <stdio.h>
      
      int main() {
      	int a = 20;
      	int b = 30;
      
      	myswap(a, b);
      
      	printf("a is %d, b is %d\n", a, b);
      
      	return 0;
      }
      ```

    * ```tex
      a is 30, b is 20
      a is 20, b is 30
      ```

  * 通过输出结果可以发现，在main函数中a和b并没有进行交换，原因就是`myswap1`函数空间中的a和b只是拷贝了main函数中的a和b，这两个a和b只是数值相等，并不是同一个空间，也就是不是同一个地址。所以在函数空间交换a和b，对于main空间中的a和b没有任何影响

  * 那么怎么才能在main函数空间中交换呢？

    * 传递地址，通过地址来找到main函数中的a和b

    * ```c
      void myswap(int *a, int *b) {
      	int temp;
      	temp = *a;
      	*a = *b;
      	*b = temp;
      	printf("a is %d, b is %d\n", *a, *b);
      }
      
      #include <stdio.h>
      
      int main() {
      	int a = 20;
      	int b = 30;
      
      	myswap(&a, &b);
      
      	printf("a is %d, b is %d\n", a, b);
      
      	return 0;
      }
      ```

    * ```tex
      a is 30, b is 20
      a is 30, b is 20
      ```



总结：当我们看到一个函数实参只是一个数值，那么无论这个函数有多复杂，仍不会改变实参，但如果实参是地址，那么这个函数就是要对实参进行改变
