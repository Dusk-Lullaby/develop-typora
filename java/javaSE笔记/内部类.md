# 内部类

## 什么是内部类？

类的五大成员：属性，方法，构造方法，构造块，内部类



在一个类的内部，再定义一个类。

举例：再A类的内部定义B类，B类就被称为内部类



内部类访问特点：

​	内部类可以直接访问外部类的成员，包括私有

​	外部类要访问内部类的成员，必须创建对象

```java
public class Car {
    private String carName;
    int carAge;
    int carColor;

    public void show(Car this) {
        //是打印调用者车的名字
        System.out.println(this.carName);

        //在代码中没有内部类的对象
        //创建对象
        Engine e = new Engine();
        System.out.println(e.engineName);
    }

    class Engine {
        String engineName;
        int engineAge;

        public void show() {
            System.out.println(engineName);
            System.out.println(carName);
        }
    }
}

```



## 内部类的分类

* 成员内部类
* 静态内部类
* 局部内部类
* 匿名内部类（掌握）

​	前3种一般很少用了解即可



### 成员内部类

* 写在成员位置，属于外部类的成员

* 成员内部类可以被一些修饰符所修饰，比如：private，默认（只能在本包），protected，public，static

```java
public class Car {	//外部类
    String carName;
    int carAge;
    int carColor;
    class Engine {	//成员内部类
        String engineName;
        int engineAge;
    }
}
```

#### 获取成员内部类

* 方式一： 内部类被private修饰时，在外部类中编写方法，对外提供内部类的对象

  ```java
  public class Outer {
  
      private class Inter {
      }
  
      //返回Inter
      public Inter getInstance() {
          return new Inter();
      }
  }
  
  ```

  ```java
  public class Test {
      public static void main(String[] args) {
  
          Outer o = new Outer();
          System.out.println(o.getInstance());
          Object ob = o.getInstance();
      }
  }
  ```

* 方式二： 直接创建格式：外部类名.内部类名 对象名 = 外部类对象.内部类对象

​			范例：Outer.Inter oi = new Outer().new Inter();



#### 外部类成员变量和内部类成员变量重名，在内部类如何访问？

System.out.println(Outer.this.变量名)

示例：

```java
public class Outer {
    private int a = 10;

    class Inter {
        private int a = 20;

        public void show() {
            int a = 30;
            System.out.println(Outer.this.a);   //10
            System.out.println(this.a);   //20
            System.out.println(a);   //30
        }
    }
}
```

```java
public class Test {
    public static void main(String[] args) {
        Outer.Inter oi = new Outer().new Inter();
        oi.show();
    }
}
```



### 静态内部类

静态内部类只能访问外部类中的静态变量和静态方法

如果想要访问非静态的需要创建对象

```java
public class Car {	//外部类
    String carName;
    int carAge;
    int carColor;
    static class Engine {	//静态内部类
        String engineName;
        int engineAge;
    }
}
```



**注意**：

 1. 静态内部类也是成员内部类的一种

 2. 静态内部类只能访问外部类中的静态变量和静态方法

 3. 如果想要访问非静态的需要创建外部类的对象

    ```java
    public class Outer {
    
        int a = 10;
        static int b =20;
    
        //静态内部类
        static class Inner {
            public void show1() {
                System.out.println("非静态方法");
                //System.out.println(a);   报错，静态中只能用静态
                System.out.println(b);
    
                //创建外部类的对象
                Outer o = new Outer();
                System.out.println(o.a);	//成功
            }
    
            public static void show2() {
                System.out.println("静态方法");
                //System.out.println(a);   报错，静态中只能用静态
                System.out.println(b);
    
                Outer o = new Outer();
                System.out.println(o.a);
            }
        }
    }
    ```



**创建静态内部类对象的格式**：外部类名.静态类名 对象名 = new 外部类名.内部类名（）；	注意：只要是 静态的东西，都可以用类名直接获取	

```java
public class Test {
    public static void main(String[] args) {
        Outer.Inner oi = new Outer.Inner();
    }
}
```



**调用非静态方法的格式**：先创建对象，用对象调用

```java
public class Test {
    public static void main(String[] args) {
        Outer.Inner oi = new Outer.Inner();

        oi.show1();		//调用非静态方法
    }
}
```



**调用静态方法的格式**： 外部类名.内部类名.方法名（）；

```java
    public static void main(String[] args) {
        Outer.Inner oi = new Outer.Inner();

        //非静态
        oi.show1();

        //静态
        Outer.Inner.show2();

    }

```



### 局部内部类

1. 将内部类定义在方法里就叫做局部内部类，类似于方法里面的局部变量
2. 外界是无法直接调用的，需要在方法内部创建对象并使用
3. 该类可以直接访问外部类的成员，也可以访问方法内的局部变量

```java
public class Outer {

    int b = 20;

    public void show() {
        int a = 10;

        //局部内部类
        class Inner {
            String name;
            int age;

            public void method1() {
                System.out.println("局部内部类方法1");
            }

            public static void method2() {
                System.out.println("局部内部类方法2");
            }

            public void show() {
                //该类可以直接访问外部类的成员
                System.out.println(b);
            }
        }

        //需要在方法内部创建对象并使用
        Inner i = new Inner();
        i.method1();
        i.show();

        Inner.method2();
    }
}
```

<font color = "blue"> 示例</font>

使用局部内部类描述使用计算器计算两个数的和


### 匿名内部类(重要)

#### 什么是匿名内部类

匿名内部类的本质就是隐藏了名字的内部类



#### 匿名内部类的格式

```
格式：
new 类名或者接口名（） {
	重写方法
}；
```

```
举例：
new Inter() {
	public void show() {
	}
}；
```



以接口为示例：

```java
interface Swim {
    public abstract void swim();
}

public class Test {
    public static void main(String[] args) {

        new Swim() {
            @Override
            public void swim() {
                System.out.println("重写游泳");
            }
        };
    }
}
```

#### 匿名内部类的使用场景

当方法的参数是接口或者类时，

以接口为例，可以传递这个接口的实现类对象，

如果实现类只使用一次，就可以用匿名内部类简化代码



应用场景：

```java
class Animal {
    void eat() {};
}

public class Test {
    public static void main(String[] args) {

        method(
                new Animal() {
                    @Override
                    public void eat() {
                        System.out.println("狗吃草");
                    }

                }
        );
    }

    public static void method(Animal a) {
        //编译看左边，运行看右边
        a.eat();
    }
}
```



接口多态：

```java
class swim {
    public void method() {};
}

public class Test {
    public static void main(String[] args) {

        swim s = new swim() {
          @Override
          public void method() {
              System.out.println("方法重写");
          }

        };

        //接口多态
        //编译看左边,运行看右边
        s.method();

    }

}
```

> 将这个Swim接口的实现类对象，赋值给一个Swim 类型的变量



既然这是一个对象，那么就可以通过这个对象来调用方法

```java
class swim {
    public void method() {};
}

public class Test {
    public static void main(String[] args) {

        new swim() {
            @Override
            public void method() {
                System.out.println("方法重写");
            }
            
        //调用自己的方法
        }.method();

    }

}
```
